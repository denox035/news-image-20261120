# news-image-20261120

Sum up 20 November's world news in one image — a make.fun entry.

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` — a front-page poster of Friday 20 November 2026 — to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). No network, fully
deterministic: every run writes the same bytes.

Stories: the global market sell-off (Nasdaq -5.3%, S&P 500 -3.7%),
Bitcoin below $56,000, Russia's barrage on Kyiv spilling into Poland,
the Strait of Hormuz standoff, and COP31 stalling in Antalya.
