A program that writes one image summing up Friday 20 November 2026's world news — a front-page poster of the global market sell-off, Bitcoin below $56,000, Russia's barrage on Kyiv spilling into Poland, the Strait of Hormuz standoff, and COP31 stalling in Antalya.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` — a front-page poster of Friday 20 November 2026 — to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). No network, fully
deterministic: every run writes the same bytes.

Stories: the global market sell-off (Nasdaq -5.3%, S&P 500 -3.7%), Bitcoin below $56,000, Russia's barrage on Kyiv spilling into Poland, the Strait of Hormuz standoff, and COP31 stalling in Antalya.
